# Cocky Cockroach - Python Terminal Game

An interactive, text-based terminal game engineered in Python using structured dictionary matrices to manage game environments, state constraints, and dynamic gameplay loops.

## Technical Skills & Architecture
* **Complex Data Modeling:** Structured a multi-layered nested dictionary system (`rooms` matrix) to map directional vectors and connect environmental nodes.
* **Procedural Behavior Mechanics:** Integrated the `random` library to inject runtime variations, creating a dynamic state engine that calculates risk encounters dynamically upon user movement.
* **String Parsing & Input Handling:** Developed input tokenizers using string manipulation loops (`choice.split()`) to parse complex terminal actions, map custom directions, and bypass case-sensitivity bugs.
* **Game Loop Integrity:** Programmed clean conditional state tracking routines to validate inventory lengths, trigger win/loss matrices, and gracefully handle runtime process exit parameters.
